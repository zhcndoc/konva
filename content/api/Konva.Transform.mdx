# Transform

```javascript
new Konva.Transform(config)
```

Transform 构造函数。在大多数情况下，你不需要在应用中使用它。因为它用于 Konva 核心内部。但如果你仍然想进行一些手动计算，这里提供了该类的文档。

## 参数

| 名称 | 类型 | 描述 |
| ---- | ---- | ----------- |
| m（可选） | `Array` | 可选的六元素矩阵 |

## 自有方法

### copy() {#copy}

复制 Konva.Transform 对象

**返回：** `Konva.Transform` 

**示例：**

```javascript
const tr = shape.getTransform().copy()
```

### point(point) {#point}

变换点

**参数：**

- `point`（Object）：2D point(x, y)

**返回：** `Object` <code>2D point(x, y)</code>

### translate(x, y) {#translate}

应用平移

**参数：**

- `x`（Number）
- `y`（Number）

**返回：** `Konva.Transform` 

### scale(sx, sy) {#scale}

应用缩放

**参数：**

- `sx`（Number）
- `sy`（Number）

**返回：** `Konva.Transform` 

### rotate(rad) {#rotate}

应用旋转

**参数：**

- `rad`（Number）：弧度制角度

**返回：** `Konva.Transform` 

### getTranslation() {#getTranslation}

返回平移

**返回：** `Object` <code>2D point(x, y)</code>

### skew(sx, sy) {#skew}

应用倾斜

**参数：**

- `sx`（Number）
- `sy`（Number）

**返回：** `Konva.Transform` 

### multiply(matrix) {#multiply}

变换乘法

**参数：**

- `matrix`（Konva.Transform）

**返回：** `Konva.Transform` 

### invert() {#invert}

反转矩阵

**返回：** `Konva.Transform` 

### getMatrix() {#getMatrix}

返回矩阵

### decompose() {#decompose}

将变换矩阵转换回节点的属性

**返回：** `Konva.Transform`。
