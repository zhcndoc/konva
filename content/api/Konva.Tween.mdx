# Tween

```javascript
new Konva.Tween(config)
```

Tween 构造函数。Tween 可以让你在节点的当前状态和新状态之间进行动画。你可以播放、暂停、反向播放、跳转、重置和完成 Tween。默认情况下，Tween 使用线性缓动进行动画。有关更多 Tween 选项，请查看 [Konva.Easings](/api/Konva.Easings.html)
