# Context

```javascript
new Konva.Context(config)
```

Konva 对原生 2d canvas context 的封装。它的 API 几乎与 2d context 相同，并增加了一些额外函数。使用 Konva 核心图形时，你不需要使用此对象。但如果你想创建[自定义图形](/docs/react/Custom_Shape.html)或[自定义命中区域](/docs/events/Custom_Hit_Region.html)，则会使用它。有关每个 2d context API 的完整信息，请参阅 [MDN 文档](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D)

### reset() {#reset}

### getCanvas() {#getCanvas}

**返回：** `Konva.Canvas` 

### clear(bounds) {#clear}

清除 canvas

**参数：**

- `bounds` (Object)（可选）
- `bounds.x` (Number)（可选）
- `bounds.y` (Number)（可选）
- `bounds.width` (Number)（可选）
- `bounds.height` (Number)（可选）
