# FastLayer

```javascript
new Konva.FastLayer(config)
```

FastLayer 构造函数。**已弃用！**请改用 `Konva.Layer(\{ listening: false\})`。图层与其自身的 canvas 元素绑定，仅用于容纳形状。如果不需要节点嵌套、鼠标和触摸交互或事件发布／订阅，则应使用 FastLayer 而不是 Layer 来创建图层。它的渲染速度大约比普通图层快 2 倍。

## 参数

| 名称 | 类型 | 描述 |
| ---- | ---- | ----------- |
| clip（可选） | `Object` | 设置裁剪 |
| clipX（可选） | `Number` | 设置裁剪 x |
| clipY（可选） | `Number` | 设置裁剪 y |
| clipWidth（可选） | `Number` | 设置裁剪宽度 |
| clipHeight（可选） | `Number` | 设置裁剪高度 |
| clipFunc（可选） | `function` | 设置裁剪函数 |

**继承自：** [Konva.Layer](/api/Konva.Layer.html)
