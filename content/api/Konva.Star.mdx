## 自有方法

### numPoints(numPoints) {#numPoints}

获取／设置点的数量

**参数：**

- `numPoints` (Number)

**返回值：** `Number` 

**示例：**

```javascript
// get inner radius
var numPoints = star.numPoints();

// set inner radius
star.numPoints(20);
```

### innerRadius(innerRadius) {#innerRadius}

获取／设置 innerRadius

**参数：**

- `innerRadius` (Number)

**返回值：** `Number` 

**示例：**

```javascript
// get inner radius
var innerRadius = star.innerRadius();

// set inner radius
star.innerRadius(20);
```

### outerRadius(outerRadius) {#outerRadius}

获取／设置 outerRadius

**参数：**

- `outerRadius` (Number)

**返回值：** `Number` 

**示例：**

```javascript
// get inner radius
var outerRadius = star.outerRadius();

// set inner radius
star.outerRadius(20);
```
