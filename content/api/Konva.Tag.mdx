# Tag

```javascript
new Konva.Tag(config)
```

Tag 构造函数。&nbsp; Tag 可以配置一个指针元素，使其指向上、右、下或左

## 参数

| 名称 | 类型 | 描述 |
| ---- | ---- | ----------- |
| config | `Object` |  |
| pointerDirection（可选） | `String` | 可以是 up、right、down、left 或 none；默认值为 none。当存在指针时，标签的位置将相对于指针尖端确定。 |
| pointerWidth（可选） | `Number` |  |
| pointerHeight（可选） | `Number` |  |
| cornerRadius（可选） | `Number` |  |

## 自有方法

### pointerDirection(pointerDirection) {#pointerDirection}

获取/设置指针方向

**参数：**

- `pointerDirection`（String）：可以是 up、right、down、left 或 none。默认值为 none。

**返回值：** `String` 

**示例：**

```javascript
tag.pointerDirection('right');
```

### pointerWidth(pointerWidth) {#pointerWidth}

获取/设置指针宽度

**参数：**

- `pointerWidth`（Number）

**返回值：** `Number` 

**示例：**

```javascript
tag.pointerWidth(20);
```

### pointerHeight(pointerHeight) {#pointerHeight}

获取/设置指针高度

**参数：**

- `pointerHeight`（Number）

**返回值：** `Number` 

**示例：**

```javascript
tag.pointerHeight(20);
```

### cornerRadius(cornerRadius) {#cornerRadius}

获取/设置 cornerRadius

**参数：**

- `cornerRadius`（Number）

**返回值：** `Number` 

**示例：**

```javascript
tag.cornerRadius(20);

// set different corner radius values
// top-left, top-right, bottom-right, bottom-left
tag.cornerRadius([0, 10, 20, 30]);
```
