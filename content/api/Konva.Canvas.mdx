# Canvas

```javascript
new Konva.Canvas(config)
```

Canvas 渲染器构造函数。它是原生 canvas 元素的包装器。通常你不需要手动使用它。

## 参数

| Name | Type | Description |
| ---- | ---- | ----------- |
| config | `Object` |  |
| width | `Number` |  |
| height | `Number` |  |
| pixelRatio | `Number` |  |

## 自有方法

### getContext() {#getContext}

获取 canvas 上下文

**返回值：** `CanvasContext` <code>上下文</code>

### getPixelRatio() {#getPixelRatio}

获取像素比

**返回值：** `Number` <code>像素比</code>

**示例：**

```javascript
var pixelRatio = layer.getCanvas.getPixelRatio();
```

### setPixelRatio(pixelRatio) {#setPixelRatio}

设置像素比。KonvaJS 会自动处理像素比调整，以便在所有设备上渲染清晰的图形。大多数台式机、低端平板电脑和低端手机的设备像素比为 1。一些高端平板电脑和手机（如 iPhones 和 iPads）的设备像素比为 2。一些 Macbook Pros 和 iMacs 的设备像素比也为 2。一些高端 Android 设备的像素比为 2 或 3。一些浏览器（如 Firefox）允许你配置视口的像素比。除非另有指定，像素比将默认为实际设备像素比。你可以在特殊情况下覆盖设备像素比，或者如果你不希望将像素比考虑在内，可以将其设置为 1。

**参数：**

- `pixelRatio`（Number）

**示例：**

```javascript
layer.getCanvas().setPixelRatio(3);
```

### toDataURL(mimeType, quality) {#toDataURL}

转换为数据 URL

**参数：**

- `mimeType`（String）
- `quality`（Number）：对于 jpg MIME 类型，取值范围为 0 到 1

**返回值：** `String` <code>数据 URL 字符串</code>
