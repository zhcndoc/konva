## 属性

### static autoDrawEnabled

Konva 是否应在发生任何更改时自动更新画布。默认值为 true。

**默认值：** `true`

**示例：**

```javascript
Konva.autoDrawEnabled = true;
```

### static hitOnDragEnabled

是否应在拖动时启用命中检测？出于性能原因，默认值为 false。但在某些少见情况下，你可能需要查看命中图并检查交集。只需将其设置为 true。

**默认值：** `false`

**示例：**

```javascript
Konva.hitOnDragEnabled = true;
```

### static capturePointerEventsEnabled

是否应捕获触摸事件并将其绑定到 touchstart 目标？这就是 DOM 元素的工作方式。具体情况是：我们在 div1 上触发 touchstart，然后从该元素移出到另一个元素 div2。DOM 将继续在 div1（而不是 div2）上触发 touchmove 事件。因为事件被“捕获”到了初始目标上。默认情况下，Konva 不会这样做，而是在指针移动时在另一个元素上触发 touchmove。

**默认值：** `false`

**示例：**

```javascript
Konva.capturePointerEventsEnabled = true;
```

### static legacyTextRendering

使用旧版文本渲染，默认使用 "middle" 基线。

**默认值：** `false`

**示例：**

```javascript
Konva.legacyTextRendering = true;
```

### static pixelRatio

全局像素比配置。KonvaJS 会自动检测当前设备的像素比。但如果你想使用自定义值，也可以覆盖此属性。请在初始化任何组件之前设置此值。

**默认值：** `undefined`

**示例：**

```javascript
// before any Konva code:
Konva.pixelRatio = 1;
```

### static dragDistance

拖动距离属性。如果你开始拖动一个节点，可能希望等待指针从起始点移动一定距离后再开始拖动。默认值为 3px。

**默认值：** `3`

**示例：**

```javascript
Konva.dragDistance = 10;
```

### static angleDeg

对角度属性使用角度值。如果你想使用弧度值，可以将此属性设置为 false。

**默认值：** `true`

**示例：**

```javascript
node.rotation(45); // 45 degrees
Konva.angleDeg = false;
node.rotation(Math.PI / 2); // PI/2 radian
```

### static showWarnings

显示有关错误或错误 API 使用方式的各种警告

**默认值：** `true`

**示例：**

```javascript
Konva.showWarnings = false;
```

### static dragButtons

配置可用于拖放的鼠标按钮。默认值为 [0, 1]，即鼠标左键和中键。

**默认值：** `[0, 1]`

**示例：**

```javascript
// enable left and right mouse buttons
Konva.dragButtons = [0, 2];
```

### static releaseCanvasOnDestroy

Konva 是否应在销毁时释放画布元素。默认值为 true。对于避免 Safari 在 macOS/iOS 上的内存泄漏问题很有用。

**默认值：** `true`

**示例：**

```javascript
Konva.releaseCanvasOnDestroy = true;
```
