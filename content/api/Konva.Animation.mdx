# Animation

```javascript
new Konva.Animation(config)
```

Animation 构造函数。

## 参数

| 名称 | 类型 | 描述 |
| ---- | ---- | ----------- |
| func | `AnimationFn` | 在每个动画帧上执行的函数。该函数会传入一个帧对象，其中包含 timeDiff、lastTime、time 和 frameRate 属性。timeDiff 属性是自上一个动画帧以来经过的毫秒数。time 属性是从动画开始时刻到当前动画帧所经过的毫秒数。lastTime 属性是上一帧的 `time` 值。frameRate 属性是当前帧率，单位为帧／秒。如果某些帧不需要重绘图层，请从函数返回 false |
| layers (可选) | `Konva.Layer\|Array` | 要在每个动画帧上重绘的图层。可以是一个图层、图层数组或 null。不指定节点将不会进行重绘 |

## 自有方法

### setLayers(layers) {#setLayers}

设置要在每个动画帧上重绘的图层

**参数：**

- `layers` (Konva.Layer|Array) (可选)：要重绘的图层。可以是一个图层、图层数组或 null。不指定节点将不会进行重绘

**返回：** `Konva.Animation` <code>this</code>

### getLayers() {#getLayers}

获取图层

**返回：** `Array` <code>Konva.Layer 的 Array</code>

### addLayer(layer) {#addLayer}

添加图层。如果图层已添加，则返回 true；否则返回 false

**参数：**

- `layer` (Konva.Layer)：要添加的图层

**返回：** `Bool` <code>如果图层已添加到动画中，则为 true，否则为 false</code>

### isRunning() {#isRunning}

确定动画是否正在运行。返回 true 或 false

**返回：** `Bool` <code>动画是否正在运行？</code>

### start() {#start}

开始动画

**返回：** `Konva.Animation` <code>this</code>

### stop() {#stop}

停止动画

**返回：** `Konva.Animation` <code>this</code>
