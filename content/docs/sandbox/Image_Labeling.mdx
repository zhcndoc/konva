图像注释工具用于标注机器学习中的训练数据、审阅医学图像以及标记照片以获取反馈。Konva.js 通过其内置的拖放、形状绘制和画布事件处理功能，让构建这些工具变得十分简单。

此演示展示了一个使用 React 和 react-konva 构建的可运行图像标注系统。阅读有关开发过程的[完整案例研究](https://lavrton.com/case-study-image-labeling-for-machine-learning/)。

该组件使用 `React`、`Konva` 和 `react-konva` 库构建。

此类应用不要求使用 `React`。但这里使用了它，因为主应用程序（使用该系统的应用程序）是使用 `React` 构建的。
